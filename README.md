# Лабораторна робота 5. Task Manager

Навчальний веб-застосунок з дисципліни **Front end**.

Тема роботи: **DOM-маніпуляції, обробка подій, Fetch API, Promises, async/await та взаємодія з REST API**.

## Мета роботи

Мета лабораторної роботи:

- навчитися маніпулювати DOM-елементами за допомогою JavaScript;
- створювати, змінювати та видаляти елементи сторінки;
- працювати з подіями користувача;
- використовувати делегування подій;
- обробляти події клавіатури та форми;
- засвоїти принципи асинхронного програмування;
- працювати з Fetch API;
- виконувати GET, POST, PATCH та DELETE-запити;
- створити інтерактивний веб-застосунок Task Manager.

## Опис застосунку

Task Manager — це простий застосунок для керування списком завдань.

Користувач може:

- завантажувати список завдань з сервера;
- додавати нові завдання;
- позначати завдання як виконані або невиконані;
- видаляти завдання;
- фільтрувати завдання за статусом;
- шукати завдання за текстом;
- бачити кількість активних завдань.
